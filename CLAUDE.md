# Инструкции для AI-ассистентов

## Ветка разработки

**Всегда работай с веткой `dev`.** Никогда не пушь напрямую в `master`.

Перед началом работы убедись что находишься на ветке `dev`:
```bash
git checkout dev
git pull origin dev
```

После внесения изменений обязательно закоммить и запушить в `dev`:
```bash
git add <изменённые файлы>
git commit -m "описание изменений"
git push origin dev
```

## Правило двух админок

**Любые изменения в функционале администраторской панели должны быть реализованы одновременно в двух проектах:**

| Проект | Тип | Аудитория |
|---|---|---|
| `BibAdmin` | WPF десктоп | Кто предпочитает приложение |
| `BibAdminWeb` | Браузер (ASP.NET Core) | Кто предпочитает веб-интерфейс |

Оба проекта должны быть функционально идентичны. Если добавляешь фичу в одном — сразу добавляй в другом.
