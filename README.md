# Biblio

Система удалённого управления компьютерами для библиотек, учебных центров и школ.

Администратор управляет всеми ПК из одного места: запускает и завершает сессии, блокирует доступ к системным функциям, ведёт финансовый учёт. Клиентское приложение работает в полноэкранном режиме и не позволяет пользователю выйти без разрешения оператора.

---

## Возможности

- Удалённый запуск, пауза и завершение сессий
- Полноэкранная блокировка клиентского ПК
- Офлайн-разблокировка по паролю (работает без сети)
- Финансовый учёт: сессии, услуги, экспорт в CSV
- Управление операторами с ограниченными правами
- Веб-интерфейс администратора (доступен с любого устройства в сети)
- Передача сессии между ПК
- Гибкая настройка ограничений (USB, диспетчер задач, PowerShell, реестр и др.)
- Автообновление клиентских приложений

---

## Компоненты

| Компонент | Назначение |
|---|---|
| **BibAdmin** | Десктопное приложение администратора (WPF) |
| **BibAdminWeb** | Веб-сервер + веб-интерфейс (порт 8080) |
| **BibClient** | Клиентское приложение на управляемых ПК |
| **BibClientService** | Windows-сервис: следит за BibClient и перезапускает при падении |
| **BibClientGuardian** | Watchdog: следит за BibClientService |

---

## Требования

**Серверный ПК (BibAdmin + BibAdminWeb):**
- Windows 10 Pro или новее
- .NET 10 Runtime
- Статический IP в локальной сети

**Клиентские ПК (BibClient):**
- Windows 10 Pro или новее
- .NET 10 Runtime
- Подключение к локальной сети

> Расчётная нагрузка: 30–50 клиентских ПК на один сервер. Реальный предел нагрузочного тестирования уточняется.

## Установка

Используется установщик на базе Inno Setup (`installer/biblio-setup.iss`).

**Серверная часть:**
1. Запустить установщик, выбрать режим **Server**
2. Установщик зарегистрирует Windows-сервис и откроет порты 8080 и 8088 в брандмауэре

**Клиентская часть:**
1. Запустить установщик на каждом клиентском ПК, выбрать режим **Client**
2. Указать IP-адрес сервера и номер ПК
3. BibClient запустится автоматически при входе пользователя

## Доступ к интерфейсам

| Интерфейс | Адрес |
|---|---|
| Веб-панель администратора | `http://<IP-сервера>:8080/admin.html` |
| Веб-панель оператора | `http://<IP-сервера>:8080/operator.html` |

> По умолчанию доступно только в локальной сети.

---

## Безопасность

- Пароль администратора хранится в виде SHA256-хеша
- Пароли операторов хешируются перед сохранением
- Сессия веб-панели ограничена 24 часами

> Рекомендуется сменить пароль администратора при первом запуске (по умолчанию: `1234`).
